Huseyin Korumtas Muzik & Ses Dosyalari Klasoru
===============================================
Kendi yaptiginiz sarkilari (.mp3, .wav, .ogg vb.) bu klasore ekleyebilirsiniz.
Ornek:
- rhythm_inside.mp3
- quiet_ambient.mp3
- juice_master.mp3
- my_heart_with_you.mp3

Dosya ekledikten sonra src/data/music.ts dosyasindaki 'src' alanina dosya yolunu (ornek: '/music/rhythm_inside.mp3') tanimlayabilirsiniz.
Dosya yuklenmedigi durumda bile Web Audio API osilator sentezleyicisi sarkilari gercek zamanli olarak canli calar!
